# Tài liệu Core: Layout

**Đường dẫn:** `static/js/core/layout.js`
**Ngôn ngữ:** JavaScript [Ngôn ngữ: JS/TS (React)]

---

## Trạng thái hiện tại

> ⚠️ File hiện tại **chỉ có 1 dòng comment** `// Layout JS` — không có logic thực tế.

File được tạo sẵn như placeholder cho logic bố cục chung trang (global layout JS) trong tương lai.

---

## Ghi chú kiến trúc

Logic co giãn/thu gọn Sidebar và Scroll Restoration hiện đang được đặt trong `static/js/components/sidebar.js`. Nếu cần tách biệt hoàn toàn logic layout khỏi component, hãy chuyển vào file này.
